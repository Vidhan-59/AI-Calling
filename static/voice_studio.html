Create a voice

Clone a real voice from a short sample, or design one from attributes. The voice is saved and can be assigned to calls below.

or

Only clone voices you have the speaker's permission to use. Calls using a cloned voice should still disclose they are automated.

Voice design was trained on English and Chinese; for Hindi/Gujarati, cloning a real recording is more stable. The designed voice is rendered once and then reused, so it sounds identical on every call.

Voice library

Type a line and press ▶ on any voice to hear it. The default voice is used wherever nothing more specific is assigned.

Assign voices to calls

Pick which voice speaks for each scenario/agent and language. "Use default" falls back to the library default. Changes apply to the next call; audio for changed voices is regenerated automatically.
